# 🎅 Кто украл твой Новый год?

**Создано по данным Кинопоиска · 2026**

Интерактивная браузерная игра в ретро-стиле, где тебе предстоит стать детективом и спасти Новый год.

## 🕵️‍♂️ О проекте
Ровно в полночь на фабрике Деда Мороза погас свет. Кто-то украл шесть волшебных игрушек, без которых праздник не наступит. Твоя задача — пройти по цехам фабрики, найти все игрушки и разгадать спрятанные в них загадки, связанные с культовыми новогодними фильмами.

## 🎮 Особенности
*   **Пиксель-арт графика:** Атмосферный визуальный стиль в духе ретро-игр.
*   **50 фильмов:** База данных из 50 популярных новогодних картин (от «Иронии судьбы» до современных хитов).
*   **Детективный геймплей:** Исследуй локацию, собирай улики и отвечай на вопросы.
*   **Мобильная адаптация:** Полная поддержка тач-управления для игры на смартфонах.
*   **Система достижений:** В зависимости от количества собранных игрушек ты получишь уникальный титул (от «Главного спасителя» до «Заснувшего под ёлкой»).

## 🚀 Как запустить
Проект представляет собой статический HTML-файл. Просто откройте `index.html` в любом современном браузере или задеплойте на GitHub Pages/Vercel/Netlify.

## 🛠 Технологии
*   HTML5 Canvas
*   Vanilla JavaScript (без фреймворков)
*   CSS3 (анимации, адаптивная верстка)
